# Security

Worldkeeper runs a local web server and handles your world backups and, with restic storage, a repository password. If you find a vulnerability, please **report it privately** via [GitHub security advisories](https://github.com/dkrasiev/worldkeeper/security/advisories/new) instead of opening a public issue.

This is a personal project shared as-is: there is no guaranteed response time, but security reports get priority.

Only the latest release receives fixes.
